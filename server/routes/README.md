# Server Routes

This directory contains API route modules for URMIS. Each top-level subfolder in `server/routes/` corresponds to a domain area in the backend architecture.

## Recommended structure

- `platform/`
- `auth/`
- `registration/`
- `institution/`
- `staff/`
- `students/`
- `courses/`
- `assessments/`
- `results/`
- `examination/`
- `approval/`
- `documents/`
- `reports/`
- `communication/`
- `settings/`
